# Рисунок 7 — Диаграмма последовательностей: загрузка файла

```mermaid
sequenceDiagram
    actor Клиент
    participant Сервер
    participant Авторизация
    participant Разбор_multipart as Разбор multipart
    participant Диск

    Note over Клиент,Сервер: Этап 1 — Получение формы загрузки

    Клиент->>Сервер: GET /
    Сервер-->>Клиент: 200 OK + HTML-форма с полем выбора файла

    Note over Клиент,Диск: Этап 2 — Загрузка файла

    Клиент->>Сервер: POST /upload<br/>Authorization: Basic <base64><br/>Content-Type: multipart/form-data; boundary=...<br/>Content-Length: N

    Сервер->>Сервер: Разбор HTTP-заголовков запроса

    alt Авторизация включена
        Сервер->>Авторизация: Проверка учётных данных
        Авторизация->>Авторизация: Декодирование Base64-токена
        Авторизация->>Авторизация: Сравнение с логином и паролем из конфига

        alt Учётные данные неверны
            Авторизация-->>Сервер: Отказ
            Сервер-->>Клиент: 401 Unauthorized
        else Учётные данные верны
            Авторизация-->>Сервер: Подтверждение
        end
    end

    Сервер->>Диск: Создание временного файла upload.bin
    Диск-->>Сервер: Дескриптор файла

    Сервер->>Разбор_multipart: Приём тела запроса по сокету

    loop Пока не принято Content-Length байт
        Разбор_multipart->>Разбор_multipart: Чтение следующего фрагмента данных
    end

    Разбор_multipart->>Разбор_multipart: Поиск разделителя и заголовков части
    Разбор_multipart->>Разбор_multipart: Извлечение имени файла
    Разбор_multipart->>Диск: Запись данных файла
    Диск-->>Разбор_multipart: Подтверждение записи

    alt Разбор завершился ошибкой
        Разбор_multipart-->>Сервер: Ошибка разбора
        Сервер->>Диск: Удаление временного файла
        Сервер-->>Клиент: 400 Bad Request
    else Разбор успешен
        Разбор_multipart-->>Сервер: Имя файла получено
        Сервер->>Диск: Переименование файла в полученное имя
        Сервер-->>Клиент: 200 OK: File uploaded: <имя файла>
    end
```
